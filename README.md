# SushiGoOffice
sushiGo é um painel administrativo para restaurantes de sushi, criado para simplificar a gestão operacional. Centraliza o controle de estoque de ingredientes (peixe, arroz, algas, molhos), monitora a validade de itens perecíveis e evita desperdício. Também unifica outras atividades do restaurante, tornando a operação mais organizada.
